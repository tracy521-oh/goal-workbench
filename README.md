# 植物生长日记 · 个人目标工作台

公考备考 / 攒钱规划 / 长期生活配套，三位一体的个人目标综合管理 PWA。

- 纯前端、纯本地离线：数据存浏览器 localStorage，不上传任何服务器
- 支持手机「添加到主屏幕」安装为独立 App，断网可用
- 永久免费、无订阅、无广告、无内购

## 板块
1. 公考备考：任务库（五大模块、看板/清单/表格/日历四视图）、每日打卡、国考/吉林省考双线四阶段进度、吉林特色考点标记、每周学习小结
   - 每日时政打卡 10 题：依据历年国考、吉林省考考情整理的题库，按日期自动抽题、评分、错题一键入错题本
   - 申论精读素材库：人民日报、半月谈等权威评论文章，按主题归类，附金句立意，可检索原文
   - 错题本：记录行测/申论/时政错题，标记掌握、来源追踪，与时政打卡打通
2. 攒钱规划：总存款目标 + 独立医疗备用金（专款专用），收支流水三分类，月度结余与达成时间预估，弹性消费超支提醒，消费避雷清单
3. 长期生活配套：作息/运动/体检目标与打卡，每周状态评分

## 使用
用手机或电脑浏览器打开部署地址（GitHub Pages），点击「添加到主屏幕」即可安装为独立 App。

## 部署
项目为静态站点，入口 index.html。可直接部署到任意免费静态托管（GitHub Pages / Netlify / Cloudflare Pages）。
