# 上岸计划 · 个人目标工作台

公考备考 / 攒钱规划 / 长期生活配套，三位一体的个人目标综合管理 PWA。

- 纯前端、纯本地离线：数据存浏览器 localStorage，不上传任何服务器
- 支持手机「添加到主屏幕」安装为独立 App，断网可用
- 永久免费、无订阅、无广告、无内购

## 使用
用手机或电脑浏览器打开部署地址（GitHub Pages），点击「添加到主屏幕」即可。

## 板块
1. 公考备考：行测/申论/真题/时政/理论 任务库，看板/清单/表格/日历四视图，每日打卡，国考·吉林省考双线四阶段进度
2. 攒钱规划：总存款目标 + 独立医疗备用金（专款专用），收支流水，月度结余与达成时间预估，消费避雷清单
3. 长期生活配套：作息/运动/体检打卡，每周日固定复盘（三段式模板自动预填）

## 部署
项目为静态站点，入口 index.html。可直接部署到任意免费静态托管（GitHub Pages / Netlify / Cloudflare Pages）。
