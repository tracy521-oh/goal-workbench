# 植物生长日记 · 个人目标工作台

公考备考 / 攒钱规划 / 生活配套 / 作家成长路 四位一体，纯本地离线 PWA。

## 板块
- **总看板**：三大目标进度卡片 + 生命之树（累计水滴浇灌大树）+ 今日三件要事 + 快捷入口
- **公考备考**：任务库（五模块·看板/清单/表格/日历）、每日打卡、四阶段双线进度、时政打卡 10 题、申论精读、错题本
- **攒钱规划**：总存款 + 医疗备用金（锁定）、收支流水、月度预算、存款达成预估、消费避雷
- **生活配套**：作息 / 运动 / 体检管理 + 每周复盘
- **作家成长路**：小说章节增删改、正文自动保存与字数统计、下载 Word、创作日历（当日 ≥2000 字浇灌一壶水）
- **每周复盘**：固定模板自动加载，三段式结构

## 奖励体系（浇灌生命之树）
- 基础奖励 1 滴水，按任务难度设定含水量（简单1 / 普通2 / 困难3 / 挑战5）
- 学习打卡 +2、每周复盘 +3、生活达标 +1~2、避雷记录 +1、月度结余达标 +3
- 作家当日创作破 2000 字 → 浇灌一壶水（+10 滴水）
- 累计水滴推进大树成长：种子 → 发芽 → 幼苗 → 小树 → 枝繁叶茂 → 参天大树
